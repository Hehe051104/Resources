# 📝 图像识别-文字与指纹 期末复习总结

## 1. OCR 文字识别 (重点)

### 1.1 定义与任务演变
*   **传统定义**：通过检测暗、亮模式确定形状，并将形状翻译成计算机文字。
*   **现代定义**：OCR 已成为文字检测、文字识别、图表识别等各类任务的代称。

### 1.2 文本检测 (Scene Text Detection)
**目标**：识别图片中所有的文本实例，如单词或一行话。

| 方法类别 | 基本思路 | 典型算法与特点 |
| :--- | :--- | :--- |
| **基于 Box-regression** | 利用目标检测方法（如 Faster R-CNN）直接回归位置 | • **TextBoxes++**：基于 SSD 回归四个顶点。<br>• **EAST**：预测像素距离边缘的偏移量。<br>• **RRPN**：旋转候选区域网络，用于检测带倾斜角的文本。 |
| **融入位置信息** | 预测边缘或像素位置并优化 | • **PixelLink**：采用实例分割方法分割文本行。<br>• **PSENet**：通过渐进尺度扩展（Progressive Scale Expansion）检测形状复杂的文本。 |
| **基于关系 (Link)** | 检测局部片段并通过连接得到文本行 | • **SegLink**：检测局部片段（Segments）并通过连接（Links）得到任意长度的文本行。 |
| **基于字符感知** | 回归字符中心概率和连接关系 | • **CRAFT**：回归字符中心概率和字符间的连接关系。 |

### 1.3 文本识别 (Scene Text Recognition)
**任务**：识别裁剪后图片中的字符序列。

*   **常用方法**：基于序列的方法（如 LSTM），逐个识别字符。
*   **核心挑战与方案**：
    *   **不规则文本**：使用图片修正网络（如 **ASTER** 预测控制点进行修正）。
    *   **特征提取**：引入 **Attention 模块**。
    *   **序列识别**：**MASTER** 采用 Transformer 架构，不再依赖 LSTM。
    *   **对齐问题**：修改 Loss 函数，如 **ACE** 忽略位置和顺序，仅通过字符数量计算 Loss。

### 1.4 端到端 (End-to-End) 文本识别
*   **Pipeline**：通常先获取旋转边界框 $\rightarrow$ 在特征图上采样 $\rightarrow$ 利用序列模型预测。
*   **代表算法**：**FOTS**、**Mask TextSpotter**。

## 2. 🖐️ 指纹识别 (重点)

指纹识别是一个多步骤的图像处理与特征匹配流程：

1.  **指纹分割**：将指纹区域从背景中分离。
2.  **局部脊线处理**：
    *   **方向预估**：估算脊线的局部走向。
    *   **频率计算**：计算单位长度内的脊线数量。
3.  **指纹增强**：使用一组 **Gabor 滤波器** 进行上下文卷积（Contextual Convolution），提升脊线清晰度。
4.  **细节点 (Minutiae) 提取**：
    *   将脊线图片二值化并细化（Thinning）。
    *   检测 **终结点 (Termination)** 和 **分叉点 (Bifurcation)**。
5.  **特征表征与匹配**：
    *   **细节点方向**：根据脊线走向计算该点的角度。
    *   **MCC (Minutia Cylinder-Code)**：最著名的指纹特征表征技术。
    *   **匹配**：计算特征相似度的均值作为最终评分。

---

## 3. 🎙️ 声纹识别 (扩展阅读)

讲义简要介绍了说话人识别（Speaker Recognition）的两种模式：

*   **说话人验证 (Speaker Verification)**：**1:1 比对**，判定“他是否在说话？”。
*   **说话人辨认 (Speaker Identification)**：**1:N 比对**，判定“谁在说话？”。

> 1.  **OCR 算法逻辑**：重点区分 **CTPN**（LSTM 结合垂直 Anchor）、**EAST**（FCN 全像素回归）和 **SegLink**（片段连接）的设计初衷。
> 2.  **指纹处理流**：掌握从“增强”到“提取细节点”再到“MCC 特征”的先后顺序。
> 3.  **数据集**：了解常用 OCR 数据集（如 ICDAR 系列）的标注级别（字符/单词/文本线）。
