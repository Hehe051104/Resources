# 计算机视觉：传感器与成像几何基础（考试重点整理）

## 一、计算机视觉的研究内容与体系

### 1. 计算机视觉定义
- **定义**：以图像（视频）为输入，以对环境的表达（representation）和理解为目标的学科
- **视觉处理三阶段**：
  - **底层处理**：知识少（线性滤波、边缘检测、纹理）
  - **中层处理**：知识多（图像分类与识别、图像检索、图像captioning）
  - **高层处理**：知识多（图像理解、场景理解）

### 2. 研究内容体系
| 编号 | 内容 | 说明 |
|------|------|------|
| 01 | 预处理 | 图像处理技术，抽取场景基本特征 |
| 02 | 物体识别 | 根据模型知识识别图像中物体并确定类别 |
| 03 | 建三维描述 | 恢复2.5维信息，重建物体完整三维图 |
| 04 | 拓扑关系图 | 建立图像中物体的拓扑关系图 |
| 05 | 体系结构 | 并行结构、分层结构、信息流结构等 |
| 06 | 输入设备 | 成像设备和数字化设备的研制 |

## 二、视觉传感器与数码相机

### 1. 视觉传感器
- **定义**：机器视觉系统信息的直接来源，主要由一个或两个图形传感器组成
- **功能**：获取机器视觉系统需要的原始图像
- **精度**：不仅与分辨率有关，还与被测物体的检测距离相关（距离越远，精度越差）

### 2. 数码相机模型
**构造**：光圈 → 快门 → 光学器件 → 相机辐照度 → 光学转换部分 → 光电转换部分 → 图像处理部分

#### 关键组件：
- **光圈**：
  - F值越小表示光圈越大
  - F2.8：大光圈，营造背景模糊的浅景深
  - F16：小光圈，主体与背景都清晰

- **快门**：
  - 控制光线照射感光元件时间
  - 快门速度：曝光时间长短（光线充足时短，光线不足时长）

- **光电传感器**：
  - **CCD**：电荷耦合元件
  - **CMOS**：互补金属氧化物半导体

- **ISO**：
  - ISO越高，接受光量越多，画面越亮
  - ISO越高，画面噪声（颗粒感）也越多

- **图像处理**：
  - **去马赛克**：从CFA（Bayer模式）输出重建全色图像
  - **白平衡**：对三原色的全局调整，适应不同光照条件
  - **Gamma校正**：补偿不同输出设备的颜色显示差异
  - **压缩**：JPEG，JPEG2000，MPEG7

## 三、成像几何基础

### 1. 基本几何变换
| 变换类型 | 描述 | 特点 |
|---------|------|------|
| 平移 | 位置移动 | 无旋转、无缩放 |
| 尺度变换 | 大小变化 | 保持形状 |
| 旋转 | 方向变化 | 保持大小、位置 |
| 刚体运动 | 旋转+平移 | 保持形状和大小 |
| 刚体+尺度变换 | 旋转+平移+缩放 | 保持形状 |
| 仿射变换 | 保持平行性 | 保持直线性 |
| 投影变换 | 透视变换 | 非线性变换 |

### 2. 针孔相机模型
- **关键参数**：
  - f = 焦距
  - c = 相机中心
  - 成像平面

- **坐标系**：
  - 世界坐标（物体坐标）(U,V,W)
  - 相机坐标(X,Y,Z)
  - 像平面坐标(x,y)
  - 数字图像坐标(u,v)

- **透视投影**：
  - 3D点 → 2D点：(x',y',z') → (x,y) = (x'/z', y'/z')
  - **齐次坐标**：(x,y,1) = (kx,ky,k)

### 3. 相机成像矩阵
- **世界坐标到相机坐标**：P_C = R(P_W - C)
- **整个成像过程**：P_pixel = K[R|t]P_world
  - K：内参矩阵（包含焦距等）
  - R：旋转矩阵
  - t：平移向量

### 4. 双目视觉

#### (1) 平行光轴情况
- 左相机坐标：xl = fX/Z, yl = fY/Z
- 右相机坐标：xr = f(X-Tx)/Z, yr = fY/Z
- **深度信息**：Z与视差d成反比

#### (2) 非平行光轴情况
- **对极几何**：
  - **极点**：相机坐标原点在另一像平面上的像
  - **极平面**：由两个相机坐标原点和物点P组成的平面
  - **极线**：极平面与两个像平面的交线
  - **极线约束**：两极线上点的对应关系

- **本质矩阵（Essential Matrix）**：
  - E = RS（秩为2）
  - 仅依赖于外部参数R和T

- **基本矩阵（Fundamental Matrix）**：
  - F = M_r^-1 R S M_l^-1（秩为2）
  - 依赖于内部参数和外部参数

### 5. 单应变换（Homography）
- **定义**：三维物体在特定条件下成像可表示为单应变换
- **类型**：
  - Isometries（等距变换）：保持距离
  - Similarities（相似变换）：保持形状
  - Affine transformations（仿射变换）：保持平行性
  - Homographies（单应变换）：一般透视变换

- **单应矩阵**：H
- **单应估计**：Direct linear transform

## 考试重点提示

1. **相机成像过程**：理解从世界坐标到数字图像的完整转换过程
2. **双目视觉**：平行光轴情况下的深度计算，非平行光轴情况下的极线约束
3. **本质矩阵与基本矩阵**：区别与联系（本质矩阵用相机坐标，基本矩阵用像素坐标）
4. **几何变换类型**：掌握各种变换的定义、特点和应用
5. **数码相机参数**：光圈、快门、ISO、白平衡的作用与关系

> 提示：考试可能涉及计算题，重点掌握透视投影公式、双目视觉深度计算、基本矩阵与本质矩阵的关系。
