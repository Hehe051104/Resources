# 图像处理基础（考试重点整理）

## 一、彩色图像与颜色空间

### 1. RGB颜色空间
- **组成**：红(R)、绿(G)、蓝(B)三原色
- **局限性**：
  - 三个分量都与亮度密切相关
  - 均匀性较差（人眼对不同颜色敏感度不同）
  - 欧氏距离度量与人眼视觉偏差较大

### 2. HSV颜色空间
- **组成**：色调(Hue)、饱和度(Saturation)、明度(Value)
- **特点**：
  - H：0°~360°，表示色彩信息（0°=红，120°=绿，240°=蓝）
  - S：0%~100%，表示颜色深浅程度（S=0为白色）
  - V：0%~100%，表示明暗程度（V=0为黑色）
- **优势**：更直观，适合图像识别

### 3. HLS颜色空间
- **组成**：色调(Hue)、饱和度(Saturation)、亮度(Lightness)
- **与HSV区别**：L表示亮度，V表示明度
- **应用**：检测白色物体时更准确（白色仅由L决定）

### 4. YUV/YCbCr颜色空间
- **组成**：
  - Y：亮度（Luminance）
  - U/V或Cb/Cr：色度（Chrominance）
- **应用**：
  - YUV：模拟信号，广播电视
  - YCbCr：数字信号，JPEG、MPEG、H.264/5等压缩标准

### 5. CIE L*a*b*颜色空间
- **国际标准**：与设备无关的色彩表示
- **组成**：
  - L*：明亮度（全白到全黑）
  - a*：红到绿色
  - b*：蓝到黄色

## 二、图像的数值表示与分辨率

### 1. 图像表示
- **RGB图像**：高度×宽度×3（三个通道）
- **计算机视角**：图像就是数字矩阵（像素值）

### 2. 图像分辨率
- **定义**：X方向像素数 × Y方向像素数
- **影响**：分辨率越高，显示像素越多，图像越清晰

## 三、图像二值化（图像分割）

### 1. 基本概念
- **图像分割**：将图像分成不相交的有物理意义的区域集合
- **二值化**：将灰度图像转换为只有黑白两色的图像

### 2. 阈值方法
#### (1) 固定阈值
```matlab
g(x,y) = { 0, f(x,y) < T; 1, f(x,y) ≥ T }
```

#### (2) 自动阈值选择
- **循环阈值选择**：迭代调整阈值以获得更好分割

#### (3) 大津法（Otsu's Method）
- **原理**：最大化阈值后黑白像素的类间方差
- **MATLAB函数**：`graythresh()`、`im2bw()`

## 四、图像量化

### 1. 基本概念
- **定义**：使用多大范围的数值表示每个像素点
- **量化级别**：n = 2^b（b为量化位数）
  - b=8：256个灰度级
  - b=1：2个灰度值（二值图像）

### 2. 均匀量化
- **方法**：将灰度范围等分为n个区间，映射到0~n-1
- **问题**：位数减少会导致轮廓效应（contouring effect）

## 五、图像几何操作

### 1. 图像插值（内插）
#### (1) 最近邻内插
- **方法**：新像素值 = 最近原像素值
- **缺点**：产生块状效应和锯齿边缘

#### (2) 线性内插
- **一维**：F = f(x1) + λ[f(x2) - f(x1)]

#### (3) 双线性内插
- **公式**：
```
f(x',y') = f(x+1,y+1)λμ + f(x+1,y)(1-μ)λ + 
           f(x,y+1)(1-λ)μ + f(x,y)(1-λ)(1-μ)
```
- **优点**：比最近邻更平滑

#### (4) MATLAB实现
```matlab
B = imresize(A, m, 'nearest');    % 最近邻
B = imresize(A, m, 'bilinear');   % 双线性
B = imresize(A, m, 'bicubic');    % 双三次
```

### 2. 图像旋转
#### (1) 旋转变换公式
- **逆时针旋转θ**：
```
[x']   [cosθ  -sinθ] [x]
[y'] = [sinθ   cosθ] [y]
```

#### (2) 实现方法
- **反向映射**：对旋转后图像的每个像素，反向旋转到原图像位置，通过插值得到像素值

#### (3) MATLAB实现
```matlab
B = imrotate(A, angle, 'bilinear');  % 逆时针旋转
B = imrotate(A, angle, 'bilinear', 'crop');  % 保持原尺寸
```

### 3. 仿射变换
- **定义**：平移、旋转、缩放的线性组合
- **矩阵表示**：
```
[x2]   [a11 a12] [x1]   [b1]
[y2] = [a21 a22] [y1] + [b2]
```
- **应用**：校正透视失真、几何畸变

## 六、图像边缘检测

### 1. 边缘检测基础
- **边缘定义**：图像局部亮度变化最显著的部分
- **边缘特性**：
  - **方向**：沿边缘走向灰度变化平缓
  - **幅度**：垂直边缘走向灰度变化剧烈
- **检测原理**：用局部图像微分技术获得边缘检测算子

### 2. 经典边缘检测算子

#### (1) Roberts算子
- **模板大小**：2×2
- **特点**：简单但对噪声敏感
- **对角线梯度模板**：
```
[1  0]    [0  1]
[0 -1]    [-1 0]
```

#### (2) Prewitt算子
- **模板大小**：3×3
- **水平模板**：
```
[-1 0 1]
[-1 0 1]
[-1 0 1]
```
- **垂直模板**：
```
[-1 -1 -1]
[ 0  0  0]
[ 1  1  1]
```

#### (3) Sobel算子
- **改进**：在Prewitt基础上，中心系数权重为2
- **优势**：能较好抑制噪声
- **水平模板**：
```
[-1 0 1]
[-2 0 2]
[-1 0 1]
```

### 3. MATLAB边缘检测
```matlab
BW = edge(I, 'sobel');    % Sobel方法
BW = edge(I, 'prewitt');  % Prewitt方法  
BW = edge(I, 'roberts');  % Roberts方法
BW = edge(I, 'canny');    % Canny方法（最常用）
```
