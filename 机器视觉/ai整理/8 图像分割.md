# 🖼️ 机器视觉复习总结：图像分割 (Image Segmentation)

---

## 1. 图像分割概述 (Overview)

### 1.1 定义
**图像分割**是将图像划分为多个片段的过程。在此过程中，图像中的每个像素都与一个对象类型相关联，旨在简化图像表示并提取感兴趣区域。

### 1.2 内容分类
图像中的内容通常分为两类：
*   **Things（可数物体）**：具有特定形状和边界的可计数实例目标（如人、车），每个实例有唯一 ID 区分。
*   **Stuff（不可数材质）**：无定形的背景或纹理区域（如天空、草地、道路），通常没有实例 ID。

### 1.3 任务分类

| 任务类型 | 方法简介 | 关注重点 |
| :--- | :--- | :--- |
| **语义分割 (Semantic)** | 为每个像素分配类别标签，同一类对象使用相同标签。 | 关注 **Stuff** 部分 |
| **实例分割 (Instance)** | 检测并区分不同的物体实例，即使是同类对象也有独立标签。 | 关注 **Things** 部分 |
| **全景分割 (Panoptic)** | 结合上述两者，为每个像素分配语义标签和唯一实例标识符。 | 同时关注 **Things** 和 **Stuff** |

## 2. 传统方法：K-means 聚类

### 2.1 原理与步骤
**K-means** 是一种常用的无监督聚类算法，目标是将数据点划分为 $K$ 个类簇，并使簇内中心度量最小化。

1.  **确定 K 值**：设定类簇数量 $K$。
2.  **选择质心**：随机选择 $K$ 个点作为初始质心。
3.  **点分配**：计算每个像素点到质心的距离，将其划归到最近的质心所属的类。
4.  **重新定义质心**：根据当前簇内所有点重新计算质心（均值）。
5.  **迭代收敛**：重复步骤 3-4，直到新旧质心距离小于阈值或达到最大迭代次数。

### 2.2 优缺点
*   ✅ **优点**：简单易懂，运算速度快。
*   ❌ **缺点**：仅适用于连续型数据，需预先指定 $K$ 值，且对初始质心敏感。

## 3. 语义分割模型 (Semantic Segmentation)

### 3.1 经典模型对比

*   **SegNet**
    *   基于 VGG16 的编码器-解码器结构。
    *   **核心创新**：使用 **最大池化索引 (Pooling Indices)** 进行非线性上采样，减少了学习参数，保留了边缘信息。

*   **U-Net**
    *   最初用于生物医学图像分割。
    *   **结构特点**：U 型结构，由 **收缩路径 (Contracting Path)** 捕获上下文信息和 **扩展路径 (Extending Path)** 实现精确定位组成。
    *   **跳跃连接 (Skip Connections)**：将浅层特征拼接到深层，融合细节与语义。

*   **DeconvNet**
    *   由卷积网络（提取特征）和反卷积网络（生成形状）组成。
    *   利用反池化恢复位置信息，反卷积捕捉细节。

*   **FCN (全卷积网络)**
    *   深度学习图像分割的开山之作。
    *   **核心**：将分类网络（如 VGG, ResNet）末端的所有全连接层替换为卷积层，从而输出二维特征图（Heatmap），解决像素级分类问题。

### 3.2 DeepLab 系列 (Google 团队)

*   **DeepLabV1**：引入 **空洞卷积 (Atrous Convolution)**，在不降低特征图尺寸的前提下增大感受野。
*   **DeepLabV2**：提出 **空洞空间金字塔池化 (ASPP)**，通过多采样率的空洞卷积提取并融合多尺度特征。
*   **DeepLabV3+**：进一步探讨了 Xception 模型和解码模块，构建了更强的编码-解码网络，边缘分割效果更好。

## 4. 实例分割模型 (Instance Segmentation)

### 4.1 发展历程 (目标检测基础)
*   **R-CNN**：提取候选区域 $\rightarrow$ CNN 提取特征 $\rightarrow$ SVM 分类。效率极低。
*   **Fast R-CNN**：整张图一次特征提取，引入 **RoIPooling** 映射特征。
*   **Faster R-CNN**：提出 **候选区域网络 (RPN)**，在特征图上产生候选框，大幅提速，实现端到端训练。

### 4.2 核心模型

*   **Mask R-CNN**
    *   在 Faster R-CNN 基础上增加了一个二值 Mask 分支（预测分割掩码）。
    *   **核心改进**：用 **RoIAlign** 替换 RoIPooling，解决了量化取整导致的对齐不准问题，大幅提升了分割精度。

*   **PANet (Path Aggregation Network)**
    *   对 Mask R-CNN 的改进。
    *   **自底向上路径增强**：缩短浅层特征到深层的传播路径，保护边缘形状信息。
    *   **自适应特征池化**：让每个 Proposal 融合来自所有特征层的信息。

## 5. 全景分割模型 (Panoptic Segmentation)

### 5.1 基本概念
全景分割为每个像素分配一个 `(语义标签, 实例 ID)` 的配对。在冲突情况下，通常优先考虑物体实例（Things）。

### 5.2 kMaX-DeepLab
最新的模型之一，从 **K-means 聚类** 的视角重新审视 Transformer 的交叉注意力机制。
*   **组件**：像素编码器、增强像素解码器、kMaX 解码器。
*   **原理**：通过双路径 Transformer 让 CNN 层能从全局内存中读写数据，将目标查询转换为掩码嵌入向量。

## 📝 复习建议

> **重点掌握以下核心概念：**
> 1.  **空洞卷积 (Atrous Convolution)**：如何扩大感受野而不降低分辨率。
> 2.  **RoIAlign**：解决了什么问题（RoIPooling 的量化误差），原理是什么（双线性插值）。
> 3.  **编码器-解码器结构 (Encoder-Decoder)**：U-Net 和 SegNet 的典型结构及其跳跃连接的作用。
> 4.  **FCN**：全连接层转卷积层的意义。
